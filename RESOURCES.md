# Git & GitHub Resources

## Knowledge

- [Zine: _How Git Works_ — Julia Evans](https://wizardzines.com/zines/git/)
  Illustrated, one sitting, $12. Use for: commits, branches, HEAD, the mental model (Phase 1).
- [Interactive: Learn Git Branching — Peter Cottle](https://learngitbranching.js.org/)
  Free browser simulation. Do *Introduction* and *Ramping Up* only. Use for: watching the commit graph move (Phases 1–3).
- [Book: _Pro Git_, 2nd ed. — Chacon & Straub](https://git-scm.com/book/en/v2)
  Free reference spine: ch. 1, 2, 3, 5.2, 7.1–7.7. Use for: authoritative definitions and "why does it work this way".
- [Docs: About pull request merges — GitHub](https://docs.github.com/en/pull-requests/reference/pull-request-merges)
  Use for: squash vs merge commit vs rebase, and what each means for `git revert` (task 1.2).
- [Docs: GitHub Docs](https://docs.github.com/)
  Primary source for every Phase 4 task (rulesets, Actions, releases, LFS, push protection).
- [Site: Oh Shit, Git!?!](https://ohshitgit.com/)
  Free, 9 recipes. Use for: the rescue card (Phase 3). Says `master`; some recipes use `reset --hard`, so practise in git-learning only.
- [Exercises: git-katas — Eficode](https://github.com/eficode-academy/git-katas)
  Local drills. Use for: merge-conflict, 3-way-merge, rebase, reset (Phase 3).
- [Blog: Confusing git terminology — Julia Evans](https://jvns.ca/blog/2023/11/01/confusing-git-terminology/)
  Use for: seeding `reference/glossary`.
- [Blog: Rebasing: what can go wrong — Julia Evans](https://jvns.ca/blog/2023/11/06/rebasing-what-can-go-wrong-/)
  Use for: rebase risks (Phase 3).
- [Course: GitHub Skills](https://learn.github.com/skills)
  Free, 15–60 min bot-taught repos. Use for: *Review pull requests*, *Resolve merge conflicts*, *Hello GitHub Actions*, *Release-based workflow*, *Introduction to secret protection*, *Introduction to repository management* (Phases 2–4). Keep copies public.
- Optional: [MIT Missing Semester 2026](https://missing.csail.mit.edu/2026/version-control/), [Mahler: Core Concepts](https://www.youtube.com/watch?v=uR6G2v_WsRA), [Chacon: So You Think You Know Git](https://www.youtube.com/watch?v=aolI_Rz0ZqY), [Master.dev: Everything Git](https://master.dev/courses/everything-git/) ($39, one month in Phase 3 at most).
